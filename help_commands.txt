Дополнительные опции для обучения:
model=gpt2 - использовать GPT-2
model=mistral - использовать Mistral
model.model.training.per_device_train_batch_size=8 - изменить размер батча
model.model.training.learning_rate=1e-5 - изменить скорость обучения
training.training.num_train_epochs=3 - изменить количество эпох



LoRA (самый простой и эффективный):
python src/train.py peft.method=lora

QLoRA (для больших моделей):
python src/train.py peft.method=qlora model.model.name=mistralai/Mistral-7B-v0.1

GRPO:
python src/train.py training.training.method=grpo

GSPO:
python src/train.py training.training.method=gspo

FSDP (включить):
python src/train.py training.training.fsdp.enabled=true

FSDP (GPT-2 preset):
python src/train.py training=fsdp_gpt2

FSDP (Mistral preset):
python src/train.py training=fsdp_mistral

Prefix Tuning:
python src/train.py peft.method=prefix_tuning

Prompt Tuning:
python src/train.py peft.method=prompt_tuning

Каждый метод имеет свои преимущества:
LoRA: хороший баланс между качеством и эффективностью
QLoRA: для работы с большими моделями на ограниченном железе
Prefix Tuning: для задач с ограниченным контекстом
Prompt Tuning: для простых задач с малым количеством примеров


Запустить TensorBoard для просмотра метрик:
tensorboard --logdir models/checkpoints/tensorboard


SIEM (простой запуск анализа последних событий):
python src/run_siem_simple.py

SIEM мониторинг:
python src/run_siem.py --mode monitor --interval 60 --time-window 5


Pipeline (SIEM -> QLoRA -> GSPO -> Eval):
python src/train_pipeline.py

MLflow локально:
export MLFLOW_TRACKING_URI=file:./mlruns
python src/train_pipeline.py

MLflow сервер (docker-compose):
docker compose up -d

python src/train_pipeline.py
